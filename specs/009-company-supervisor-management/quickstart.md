# Quickstart：公司主管管理

## 目錄

- [啟動](#啟動) — H2 後端與 React 前端
- [公司驗收](#公司驗收) — 公司 CRUD
- [主管驗收](#主管驗收) — 既有使用者升任
- [綁定驗收](#綁定驗收) — 多主管與一人一公司
- [權限驗收](#權限驗收) — API 與頁面

## 啟動

1. 後端以 `test` profile 啟動於 8080。
2. 前端啟動於 5173。
3. 使用 `admin / admin123` 登入。

## 公司驗收

1. 前往 `/company-supervisor-management` 的「公司」標籤。
2. 新增「測試公司」、修改名稱與說明。
3. 以名稱查詢確認資料，再於無綁定時刪除。

## 主管驗收

1. 在「主管」標籤選擇既有 `user` 帳號並輸入職稱。
2. 建立後確認姓名、帳號、職稱及主管角色。
3. 修改職稱並確認值更新。

## 綁定驗收

1. 建立兩家公司與兩名主管。
2. 將兩名主管綁至同一家公司，確認皆成功。
3. 嘗試把其中一名主管綁至第二家公司，確認被拒絕。
4. 依公司名稱及主管名稱查詢；取消後確認可改綁。

## 權限驗收

1. 使用 `user / admin123` 登入。
2. 呼叫管理 API，確認 403 與「[公司主管管理] [api] 無系統管理員權限。」。
3. 前往管理頁，確認導向無權限頁並顯示「[公司主管管理] [頁面] 無系統管理員權限。」。
