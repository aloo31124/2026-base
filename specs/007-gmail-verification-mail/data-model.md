# Data Model：Gmail 信箱驗證測試

## 目錄

- [持久化決策](#持久化決策) — 不新增資料表
- [請求模型](#請求模型) — 收件信箱
- [回應模型](#回應模型) — 遮罩收件者與時間
- [信件模型](#信件模型) — Gateway 內部資料

## 持久化決策

本功能不新增資料表。驗證碼只在單次請求的記憶體區域內存在，交給 SMTP 後即不再由系統持有；正式驗證碼核銷不在本次範圍。

## 請求模型

| 欄位 | 型別／限制 | 說明 |
|------|-------------|------|
| email | String，必填、Email 格式、最長 160 | 測試信收件地址 |

## 回應模型

| 欄位 | 型別／限制 | 說明 |
|------|-------------|------|
| maskedRecipient | String | 遮罩後收件地址 |
| sentAt | OffsetDateTime | SMTP 寄送完成時間 |

## 信件模型

`MailMessage` 為服務與 gateway 間的內部值物件，包含收件者、主旨與純文字內容；不得序列化為 API 回應或寫入日誌。
