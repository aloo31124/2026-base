# Quickstart：註冊登入管理

## 目錄

- [啟動](#啟動) — H2 測試環境
- [管理員驗收](#管理員驗收) — 政策與紀錄
- [權限驗收](#權限驗收) — API 與頁面

## 啟動

1. 後端以 `test` profile、mock mail 與 mock LINE 啟動於 8080。
2. 前端啟動於 5173。
3. 使用 `admin / admin123` 登入。

## 管理員驗收

1. 前往 `/registration-management`。
2. 更新最小長度與英文字母／數字條件。
3. 重新整理後確認政策一致。
4. 完成信箱或 LINE 首次註冊，再確認紀錄表出現成功列。

## 權限驗收

1. 使用 `user / admin123` 登入。
2. 呼叫管理 API，確認 403 與指定 API 訊息。
3. 前往管理頁，確認導向無權限頁並顯示指定頁面訊息。
