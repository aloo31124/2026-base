# Quickstart：資料庫基礎

## 目錄

- [Windows](#windows) — PowerShell 初始化
- [macOS/Linux](#macoslinux) — Shell 初始化

## Windows

`pwsh ./scripts/init-database.ps1`，可用參數覆寫 Server、DatabaseName、LoginName、Password。

## macOS/Linux

設定 `DB_SERVER`、`DB_NAME`、`DB_USERNAME`、`DB_PASSWORD` 後執行 `bash ./scripts/init-database.sh`。
