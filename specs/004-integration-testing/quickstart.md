# Quickstart：整合測試

## 目錄

- [Backend](#backend) — Gradle tests
- [Postman](#postman) — Newman
- [Cypress](#cypress) — E2E

## Backend

`backend/gradlew.bat test`

## Postman

啟動 backend 後：`cd postman && npm install && npm test`。

## Cypress

啟動 backend 與 frontend 後：`cd frontend && npm run test:e2e`
