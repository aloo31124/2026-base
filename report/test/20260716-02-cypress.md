## 重現方式

```powershell
# 先啟動 backend 與 frontend
cd frontend
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm run test:e2e
```

Codex 宿主若設有 `ELECTRON_RUN_AS_NODE`，需先清除，否則 Cypress Electron 會在 runner 啟動前退出。
